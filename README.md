# Minds of Tomorrow · solución

Landing page para una academia extraescolar de programas creativos para niños de 6 a 13 años. Solución al ejercicio de maquetación «Minds of Tomorrow».

**Demo:** https://wiliampsa11.github.io/Minds-of-tomorrow-solucion/

## Tecnologías
- HTML5 y CSS3 (diseño en columnas, banner con imagen de fondo)
- JavaScript

## Estructura
```
index.html
css/styles.css
js/codigo.js
img/
```

## Cómo verlo
Abre `index.html` en el navegador o visita la demo.
